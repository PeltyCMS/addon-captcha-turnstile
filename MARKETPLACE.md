## Cloudflare Turnstile for PeltyCMS

Drop-in bot protection for login, register, contact and order forms. Site keys stay in settings; verification runs in the WASM captcha addon.

### Features
- Login / register / ticket forms
- Server-side verify
- No custom theme PHP

### Requirements
- Cloudflare Turnstile site + secret keys
